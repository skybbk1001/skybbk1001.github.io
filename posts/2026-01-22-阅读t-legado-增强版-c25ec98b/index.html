阅读T（Legado 增强版）

2026/01/22更新于 2026/10/24明月照大江约 2,160 字 · 约 7 分钟— 次阅读

📖 简介

阅读T 是基于 Legado 的增强版分支，由明月照大江维护。

在保持原版核心阅读能力的前提下，重点补齐了以下方向：

  • ⏰ 定时任务与自动化脚本
  • 🛠️ 功能强大的代码编辑器
  • 🚀 JS 运行环境与规则兼容性
  • 🌐 HTTP 请求日志调试
  • 📖 目录分卷折叠等阅读体验优化

🎯 核心能力

2️⃣ 定时任务自动化

Cron 驱动的脚本执行引擎

  • ⏰ 支持 Cron 表达式调度脚本
  • 🔗 支持一键导入：/auto?src= 与 /autoTask?src=
  • 📚 内置多书源自动检测更新（refreshToc），实时推送通知
  • 📢 支持自定义通知（notify），可指定优先级和分组
  • 📋 任务执行历史可查看完整日志
  • 🐛 内置调试模式，单次运行查看结果

3️⃣ 规则编辑器增强

专业级代码编辑体验

  • 🎨 WebView 代码编辑器，支持自动补全、语法校验、代码折叠、搜索替换、格式化等
  • 🎯 语法错误实时检查，提升JS编写效率
  • 🔍 搜索替换支持正则表达式测试
  • 🔄 支持 CURL 转 AnalyzeURL
  • 📍 快速定位导航栏，右侧滚动条，大文本场景下性能优化
  • ⚡ WebView 预热，实现秒开

4️⃣ JS 运行环境

更强大的脚本执行能力

  • 🔧 JS 引擎切换到 htmlunit-core-js（4.21 分支），修复长期存在的 const 作用域问题
  • 🔐 为规则运行环境启用 CryptoJS
  • 📤 java.get/post/head 增加 JSON 字符串请求头重载
  • 🌐 URL 参数新增 timeout、followRedirects、resolveIp 字段
  • 🌐 HTTP 请求支持 brotli 压缩算法
  • 🌐 代理支持 socks5 服务器认证

5️⃣ HTTP 调试工具

开发者的网络透视镜

  • 📡 设置中开启「记录 HTTP 请求」后，所有网络请求自动记录到日志
  • 📊 日志中显示请求概览：🌐 [#1] GET https://xxx → 200 (234ms)
  • 🔍 点击条目弹出完整请求/响应详情（header + body）
  • 🧹 不影响请求本身，仅旁路记录，body 自动截断防 OOM

1️⃣ 书源回调系统

移植自 @Luoyacheng 分支，让书源「感知」用户操作

书源可监听 17 种事件（点击书名、分享、加入书架等），执行自定义 JS 响应。配套 showBrowser 弹窗和 copyText 剪贴板函数。

6️⃣ 阅读体验

细节打磨

  • 📁 目录分卷支持展开/折叠，默认只展开当前阅读所在分卷
  • 🎵 有声书支持下载缓存、跳过片头片尾
  • 📱 Android 16 兼容性修复
  • 🐛 原生段评支持

❓ 常见问题

Q1：阅读T和原版阅读有什么区别？

A1：阅读T是基于 Legado 的增强分支，核心阅读功能保持一致，额外增加了：

  • ⏰ 定时任务自动化
  • 🛠️ 功能更强的规则编辑器
  • 🚀 更好的 JS 运行环境兼容性
  • 🌐 HTTP 请求日志调试工具
  • 📖 目录分卷折叠等阅读体验优化

Q2：能否兼容原版阅读的数据？

A2：可以兼容。阅读T使用新的包名和签名，不会覆盖原版数据。首次使用建议先备份原版数据，再导入到阅读T中。

Q3：如何反馈问题或提出建议？

A3：欢迎通过以下方式反馈：

  • GitHub Issues：skybbk1001/legado/issues
  • 在本文下方留言

Q4：定时任务支持哪些功能？

A4：定时任务支持：

  • Cron 表达式调度
  • refreshToc 自动检测书籍更新并推送通知
  • notify 自定义通知
  • 任务日志查看与调试
  • 一键导入分享
  • 详情见定时任务编辑页右上角帮助

Q5：书源回调系统怎么用？

A5：编辑书源时勾选「事件监听」，在正文规则的「回调操作(callBackJs)」中编写 JS 代码。JS 中可以通过 event 变量判断触发的事件类型，通过 book、chapter、result 获取上下文数据。返回 true 可拦截交互类事件的默认行为。详细文档见书源编辑页右上角帮助。
